# FleetPilot V4.4

Добавлено:
- блок «План недели» на главной;
- плановый заработок по всем машинам со статусом «На линии»;
- плановые расходы недели;
- запланированные ремонты недели;
- ожидаемый остаток после плановых расходов;
- «Плановые расходы» возвращены в нижнее меню;
- «Аналитика» перенесена в раздел «Ещё».

Исправлен прогноз ТО:
- используется до 8 последних записей пробега;
- дубли дат отбрасываются;
- аномальные значения свыше 1000 км/день не учитываются;
- используется медианный дневной пробег;
- показываются остаток километров, средний пробег в день и прогноз дней;
- при малом количестве данных выводится предупреждение.

Постоянная база fleetpilot.data.v1 сохранена.
