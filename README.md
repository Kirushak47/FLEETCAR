# FleetPilot V6.1.1 One Click Service

На главной карточке автомобиля теперь можно нажать:
- Масло — сохранить замену, пробег, интервал и стоимость;
- Страховка — продлить дату и добавить стоимость;
- Техосмотр — обновить дату и добавить стоимость;
- предупреждение под карточками — сразу открыть нужное обновление.

Автоматически:
- обновляется автомобиль;
- пересчитываются предупреждения;
- создаётся запись Timeline;
- для масла создаётся выполненный ремонт;
- при выбранной опции создаётся оплаченный расход;
- карточка обновляется без открытия профиля.
