# FleetPilot V11.4 — Vehicle Status Panel

SQL выполнять не нужно.

1. Загрузи файлы в корень GitHub.
2. Открой https://kirushak47.github.io/FLEETCAR/?v=114000
3. Нажми Ctrl+F5.

Изменения:
- красный ключик убран из неудобного угла;
- под названием автомобиля появилась единая панель статусов;
- заявки, ремонты, масло, страховка и техосмотр показаны отдельными бейджами;
- каждый бейдж открывает соответствующую задачу;
- панель работает в компьютерном списке, доске, таблице и мобильной карточке;
- возвращён верхний оранжевый блок заявок водителей;
- старый плавающий ключик полностью отключён.
