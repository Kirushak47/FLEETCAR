# FleetPilot V7.5.2 — Map Tile Fix

Причина:
в V7.5.1 был указан неправильный integrity-хэш Leaflet CSS.
Браузер блокировал stylesheet, поэтому тайлы отображались мозаикой.

Исправлено:
- установлен официальный integrity-хэш Leaflet 1.9.4;
- добавлен резервный CSS позиционирования тайлов;
- карта получает повторный invalidateSize после открытия;
- service worker обновлён и удаляет старый кеш;
- версия ресурсов изменена на 752.

https://kirushak47.github.io/FLEETCAR/?v=752
