# FleetPilot V4.2

Добавлено к V4.1 без удаления текущих функций:
- несколько фотографий для одного повреждения;
- альбомы повреждений с миниатюрами;
- полноэкранный просмотр;
- листание стрелками и клавишами;
- двойной клик для увеличения;
- этапы до ремонта / в процессе / после ремонта;
- место повреждения;
- редактирование записи и удаление отдельных фото перед сохранением;
- автоматический перенос старых одиночных фото в новый формат.
