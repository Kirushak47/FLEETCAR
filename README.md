# FleetPilot V6.1.0 Adaptive Mode

Простой режим:
- скрывает Сервис, Календарь и Аналитику;
- скрывает ремонт, документы и кауцию из быстрых действий;
- оставляет Главную, Автомобили, Оплаты, Расходы и Ещё;
- упрощает профиль автомобиля;
- скрывает Историю, архивирование и удаление из профиля;
- при попытке открыть расширенный раздел возвращает на главную;
- все данные сохраняются.

Расширенный режим показывает весь функционал.

Переименовано:
- Ожидаемый остаток → Ожидаемая прибыль;
- FleetPilot Score → Состояние автопарка;
- FleetPilot Intelligence → Автоматическая сводка.
