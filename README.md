# FleetPilot V7.3 — Real OpenStreetMap

Заменена декоративная SVG-карта на настоящую интерактивную карту:

- Leaflet 1.9.4;
- OpenStreetMap;
- масштабирование колесом;
- перемещение карты мышкой;
- автоматическое приближение к городам автопарка;
- маркеры с количеством автомобилей;
- цвет маркера по состоянию;
- всплывающее окно с прибылью и количеством машин;
- фильтры по статусу;
- список городов и машин справа;
- нажатие на машину открывает её профиль;
- поддержка светлой и тёмной темы.

Важно:
- для загрузки карты нужен интернет;
- автомобили размещаются по городу из профиля;
- это не GPS и не показывает реальное положение машины;
- при неизвестном городе он останется в списке, но маркер не появится до добавления координат.
