# FleetPilot V7.9.1 — GPS Demo Mode

Добавлено:
- кнопка «Попробовать демо» в окне подключения GPS;
- 6 тестовых GPS-устройств в Варшаве;
- автоматическое сопоставление с первыми автомобилями FleetPilot;
- отдельное окно сопоставления после запуска;
- тестовые скорости и Online/Offline;
- координаты немного меняются каждые 5 секунд;
- карта обновляется без внешнего API;
- демо можно отключить обычной кнопкой «Отключить».

Как проверить:
1. Открыть Настройки / Ещё.
2. Найти блок GPS.
3. Нажать «Подключить GPS».
4. Нажать «Попробовать демо».
5. Проверить сопоставление.
6. Открыть вкладку «Карта».
