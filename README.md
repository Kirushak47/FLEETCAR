# FleetPilot V11.3 — Core Repair

## Установка

1. Supabase → SQL Editor.
2. Выполни `supabase_v11_3_core_repair.sql`.
3. Загрузи все файлы из архива в корень GitHub.
4. Открой:
   https://kirushak47.github.io/FLEETCAR/?v=113000
5. Нажми Ctrl+F5. На телефоне полностью закрой PWA и открой снова.

## Исправлено

- Ключик/иконка заявки встроен прямо в компьютерную строку автомобиля и больше не исчезает после повторного renderFleet.
- Иконка есть также в desktop board.
- Динамическая перерисовка больше не удаляет постоянные иконки.
- После сохранения статуса сервиса пользователь остаётся во вкладке «Сервис».
- Связанный ремонт прокручивается и подсвечивается.
- Пробег в форме ремонта всегда подтягивает последний подтверждённый пробег автомобиля.
- При выборе другой машины пробег обновляется автоматически.
- При сохранении ремонта пробег сначала проверяется и сохраняется на сервере.
- Источники пробега различаются: сервис, замена масла, заявка водителя.
- CRM владельца и профиль водителя получают обновлённый пробег через Realtime.
- В профиле водителя добавлено предупреждение о ближайшем сервисе.
- В профиле водителя добавлена история запланированных и завершённых работ.
