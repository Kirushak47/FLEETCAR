# FleetPilot V7.9 — Simple GPS Connection

Добавлено:
- простой раздел GPS в настройках;
- подключение по адресу API и токену;
- проверка подключения;
- импорт GPS-устройств;
- сопоставление с автомобилями FleetPilot;
- ручная синхронизация и отключение;
- GPS-статус на карточке автомобиля;
- реальные координаты используются на карте;
- без GPS сохраняется размещение по городу.

Ожидаемый универсальный JSON:
[{"id":"1","name":"Toyota Prius","latitude":52.2297,"longitude":21.0122,"speed":42,"updatedAt":"2026-08-04T14:30:00Z","online":true}]

Важно: Wialon, Navixy, Traccar и другие провайдеры могут возвращать другой формат. Для реального подключения конкретной системы потребуется адаптер или сервер-посредник.
