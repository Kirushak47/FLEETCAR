# FleetPilot V3.9 — Clean Dashboard

Изменено:
- финансовый месяц убран с главной страницы;
- верхняя финансовая сводка убрана с главной;
- карточки машин больше не показывают отдельные доходы и расходы за выбранный месяц;
- на карточке остаётся только прибыль за текущий месяц;
- выбор конкретного месяца перенесён в «Аналитику»;
- аналитика поддерживает выбранный месяц, текущий год и всё время;
- вся финансовая сводка и прибыль по машинам пересчитываются по выбранному периоду.

Постоянная база и резервные копии из V3.8 сохранены.
