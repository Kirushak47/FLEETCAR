# FleetPilot V7.10.1 — Stable Map Navigation

- GPS Demo обновляется каждые 30 секунд.
- Обновление координат не сбрасывает ручной масштаб и центр.
- Demo размещает машины возле города из карточки.
- Справа сначала показывается список городов.
- После выбора города показывается список его автомобилей.
- Есть Online, Offline, средняя скорость и последний сигнал.
- «Найти» приближает конкретную машину.
- «Все города» возвращает общий обзор.
