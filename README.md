# FleetPilot V10.6.1 — Driver Navigation & Password

SQL выполнять не нужно.

1. Загрузи все файлы на GitHub.
2. Открой:
   https://kirushak47.github.io/FLEETCAR/?v=106100
3. Нажми Ctrl+F5.
4. На телефоне полностью закрой PWA и открой снова.

Изменено:
- у водителя скрыто стандартное нижнее меню CRM;
- скрыта кнопка быстрого добавления;
- оставлено только 5 действий:
  Автомобиль / Документы / Заявка / Уведомления / Профиль;
- кнопка «Заявка» сразу открывает форму неисправности;
- «Уведомления» прокручивает к уведомлениям;
- «Профиль» открывает отдельный профиль водителя;
- кнопка «Изменить пароль» теперь открывает форму внутри приложения;
- пароль меняется напрямую через активную Supabase-сессию;
- сохранены Driver Portal, Data Recovery, Realtime и остальные функции.
