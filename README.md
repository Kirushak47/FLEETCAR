# FleetPilot V16.0 — Mobile UI Rebuild

Полная версия для первой установки V16.0. Все JS/CSS модули лежат в корне репозитория.

## Главное
- Полностью новый mobile UI, desktop не изменён.
- Нижние вкладки на телефоне удалены: теперь одна кнопка **Меню**.
- Кнопка открывает полный список разделов, разрешённых существующей ролью.
- Новый mobile Vehicle Core, карточки, формы, модальные bottom-sheet окна, списки и типографика.
- Версия централизована: V16.0 / build 160000.
- Исправлен Service Worker: он больше не запрашивает старые `/js` и `/css` папки.

## Для этой версии
Загрузить содержимое архива целиком в корень репозитория с заменой одноимённых файлов. Папку `supabase` оставить как есть/заменить содержимым из архива при необходимости.

## Дальнейшие мобильные патчи
В основном будут требовать замены только:
- `fp-roles-company.js` — права и мобильное меню;
- `fp-mobile-v16.css` — мобильный дизайн.
