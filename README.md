# FleetPilot V9 Polish Edition

Главные изменения:
- отдельный дашборд владельца;
- 6 KPI: онлайн, прибыль, водители, внимание, документы, ТО;
- живая GPS-карта с быстрым переходом к автомобилю;
- последние события;
- ТОП-5 автомобилей по прибыли;
- проблемные автомобили;
- любой блок можно скрыть и вернуть через «Настроить дашборд»;
- единые радиусы, тени, кнопки, анимации и переходы;
- skeleton-загрузка;
- мобильная версия использует ту же дизайн-систему без радикальной перестройки;
- список, таблица, доска и карта автопарка сохранены ниже дашборда.
