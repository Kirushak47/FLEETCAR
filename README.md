# FleetPilot V2.2

Добавлено:
- прибыль автомобиля = полученная аренда минус фактические ремонты и оплаченные расходы;
- прибыль за текущий месяц, год и всё время;
- налоговый профиль партнёра;
- VATowiec / без VAT;
- ryczałt с изменяемой ставкой;
- liniowy 19%;
- zasady ogólne;
- ежемесячные ZUS/взносы;
- ориентировочный VAT, PIT и фактическая прибыль после налогов;
- отдельная прибыль по каждому автомобилю;
- уникальное изображение для каждой модели.

Налоговый расчёт является ориентировочным и не заменяет расчёт бухгалтера.
