# FleetPilot V4.3 — Reorganized Premium UI

Что изменено:
- налоговый профиль и расчёт прибыли перенесены из «Аренды» в «Аналитику»;
- «Аренда» оставлена только для оплат, периодов, недель и долгов;
- главная страница упрощена;
- из карточек убраны повторяющиеся показатели страховки, техосмотра, ставки и последней оплаты;
- нижнее меню сокращено до 6 основных разделов;
- расходы, документы и резервные копии собраны в разделе «Ещё»;
- статусы ремонтов, расходов и документов переведены на русский;
- редактирование записей больше не создаёт дубли в ленте событий;
- при удалении автомобиля удаляются его повреждения и история;
- перед импортом автоматически создаётся автокопия текущей базы;
- дизайн полностью обновлён и приведён к единому стилю;
- полноэкранная галерея повреждений сохранена.
