# FleetPilot V10.7 — Vehicle Handover & History

1. Supabase → SQL Editor → New query.
2. Выполни `supabase_v10_7_vehicle_handovers.sql`.
3. Загрузи все файлы на GitHub.
4. Открой https://kirushak47.github.io/FLEETCAR/?v=107000
5. Нажми Ctrl+F5. На телефоне полностью закрой PWA и открой снова.

Тест:
1. Владелец назначает автомобиль пользователю с ролью Driver.
2. Водитель открывает «Мой автомобиль».
3. Нажимает «Принять автомобиль», вводит пробег, топливо, комплектацию и фотографии.
4. Сервер автоматически фиксирует водителя, автомобиль, дату и время.
5. При возврате водитель нажимает «Вернуть автомобиль» и повторяет осмотр.
6. Владелец открывает карточку машины → «История».
7. Там отображаются выдача, возврат, водитель, пробеги, разница километров, фото и замечания.

Сохранены все предыдущие функции: восстановление данных, Realtime, Driver Portal, профиль водителя, заявки на сервис и иконки возле автомобилей.
