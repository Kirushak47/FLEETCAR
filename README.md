# FleetPilot V7.2 Desktop Command Center

Desktop:
- переключение Список / Доска / Таблица / Карта;
- рабочий Fleet Board с drag & drop;
- таблица для 50–500 автомобилей;
- карта Польши с группировкой по городам;
- прибыль и количество авто по городу;
- фильтры карты;
- KPI;
- лента событий;
- аналитические подсказки FleetPilot AI;
- массовая смена города и статуса;
- горячие клавиши Ctrl/Cmd+N, F, P, K и Escape.

Важно:
- карта использует города, указанные в профиле автомобиля;
- это не GPS и не показывает реальное местоположение;
- GPS потребует сервер и интеграцию с трекерами.

Мобильная версия не изменена.
