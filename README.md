FleetPilot V11.7 — Service Relations

Связи сервисной задачи с расходами, профилем автомобиля и календарём.
Сервисная задача является главным источником данных: завершение создаёт/обновляет связанный расход, повторное открытие удаляет только автоматически созданный расход, изменения суммы/даты синхронизируются. Переходы между сервисом, расходом, профилем авто и календарём ведут к конкретной записи.
