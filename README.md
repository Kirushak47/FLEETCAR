# FleetPilot V14.0.1 — Vehicle Core Logic Fix

- Убран дублирующий блок «Основная информация» в профиле автомобиля.
- Кнопки «Обновить пробег» и «Запланировать ремонт» перенесены в Vehicle Core.
- В Vehicle Core сохранены пробег, масло, страховка, техосмотр, активный сервис, последнее обслуживание и Health Score.
- Отменённые и завершённые ремонты не отображаются в «Ближайших ремонтах».
- Отменённые ремонты исключены из календарных/ближайших событий автомобиля.
- Активный сервис и Health Score продолжают учитывать только активные задачи.
- Отменённые ремонты остаются доступны в истории обслуживания.
