# FleetPilot V8.0 — Stable

Основа: рабочая V7.11.2.

Исправлено без глобальных перехватчиков:
- вкладка «Большой автопарк» использует правильный renderDesktopTable;
- таблица работает от одного автомобиля;
- данные берутся напрямую из db.cars;
- ошибка одной машины больше не делает всю таблицу пустой;
- текст заменён на «Работает от 1 автомобиля»;
- мобильная карта добавлена в SIMPLE_ALLOWED_PAGES;
- карта открывается в простом режиме интерфейса;
- после открытия мобильная карта пересчитывает размер;
- кнопка «+» остаётся выше нижней навигации;
- GPS каждые 30 секунд обновляет только GPS-индикаторы и открытую карту;
- главная, таблица и аналитика не перерисовываются каждые 30 секунд.
