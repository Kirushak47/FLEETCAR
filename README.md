# FleetPilot V10.5.1 — Realtime Sync

1. Supabase → SQL Editor → New query.
2. Выполни `supabase_v10_5_1_realtime_sync.sql`.
3. Загрузи все файлы на GitHub.
4. Открой:
   https://kirushak47.github.io/FLEETCAR/?v=105100
5. Нажми Ctrl+F5 на компьютере.
6. На телефоне полностью закрой PWA/вкладку и открой заново.

Что изменено:
- Supabase Realtime для общей базы Workspace;
- изменения с компьютера автоматически приходят на телефон;
- каждое устройство получает собственный ID;
- собственное изменение не вызывает циклическую перезагрузку;
- проверка обновлений при возврате в приложение, фокусе и восстановлении интернета;
- резервная проверка облака каждые 45 секунд;
- Owner и Coordinator автоматически сохраняют изменения;
- остальные роли получают обновления, но не перезаписывают общую базу;
- статус «Все изменения сохранены» и «Обновлено с другого устройства».

Важно:
- оба устройства должны войти в один Workspace;
- на обоих устройствах должна быть версия `?v=105100`;
- после SQL Realtime начинает работать для таблицы `fleet_states`.
