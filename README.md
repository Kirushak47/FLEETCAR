FleetPilot V13.1.3 — Service Conversion Fix

Изменения:
- Плановый сервисный расход/запрос больше не дублируется в рабочей очереди после создания связанной сервисной задачи.
- Финансовая запись сохраняется в разделе «Расходы», но рабочей записью становится ремонт в «Сервисе».
- Связь хранится через linkedRepairId, дополнительно фиксируется serviceConvertedAt.
- Если связанный ремонт позже удалён без удаления расхода, расход снова может появиться как плановая сервисная запись.
- Обновлены версии ресурсов и service worker cache до V13.1.3.
