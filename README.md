# FleetPilot V3.5 — No Photos

Фотографии автомобилей полностью убраны.

Новая карточка показывает:
- статус;
- марку и модель;
- номер и арендатора;
- год;
- прибыль за месяц;
- текущий пробег;
- остаток до масла;
- страховку;
- техосмотр;
- аренду за неделю;
- последнюю оплату;
- ближайшее событие.

Цвет верхней части зависит от статуса машины.
