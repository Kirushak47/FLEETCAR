# FleetPilot V13.1.5 — Global Service Search

- Один общий поиск по всему разделу «Сервис».
- Поиск одновременно применяется к входящим заявкам, рабочей очереди и плановым сервисным расходам.
- Добавлены явные кнопки «Найти» и «Сбросить»; Enter запускает поиск.
- Отдельный поисковик во «Входящих» удалён.
- Блок «Входящие заявки водителей» можно скрыть/показать, состояние сохраняется локально.
- Блок «Планирование / Плановые сервисные расходы» можно скрыть/показать независимо, состояние сохраняется локально.
- Сохранена логика V13.1.3/V13.1.4: связанные сервисные задачи не дублируют исходные плановые запросы в рабочей очереди.
