# FleetPilot V10.6.2 — Fleet Service Alerts

SQL выполнять не нужно.

1. Загрузи все файлы на GitHub.
2. Открой:
   https://kirushak47.github.io/FLEETCAR/?v=106200
3. Нажми Ctrl+F5.

Добавлено:
- уведомление с количеством активных заявок возле вкладки «Автопарк»;
- информационная полоска сверху списка автомобилей;
- иконка 🔧 только возле автомобиля, на который водитель отправил заявку;
- число на иконке показывает количество активных заявок;
- красная иконка — движение опасно;
- жёлтая — нужен сервис;
- синяя — обычная заявка;
- нажатие на иконку открывает заявки только выбранного автомобиля;
- после закрытия или отклонения заявки иконка автоматически исчезает;
- Owner, Coordinator и Mechanic получают одинаковую актуальную информацию.
