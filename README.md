# FleetPilot V10.1.2 — Workspace Sync Fix

## Обязательно перед загрузкой приложения

1. Supabase → SQL Editor → New query.
2. Выполнить целиком `supabase_v10_1_2_sync_fix.sql`.
3. Загрузить файлы приложения на GitHub.
4. Открыть:
   https://kirushak47.github.io/FLEETCAR/?v=101200
5. Нажать Ctrl+F5 и войти повторно.

## Исправлено

- синхронизация выполняется по Workspace через защищённые RPC;
- устранён конфликт `ON CONFLICT(workspace_id)`;
- старые личные записи автоматически привязываются к автопарку;
- дубли облачных записей удаляются с сохранением самой новой;
- Owner и Coordinator могут сохранять базу;
- остальные роли могут загружать базу, но не перезаписывать её;
- ошибки RLS, схемы и индексов теперь показываются понятным текстом;
- первая синхронизация больше не делает ошибочный повторный pull.
