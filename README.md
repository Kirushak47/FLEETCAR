Исправлено:
- на компьютерной карточке остаётся только один ключик;
- старый динамический значок больше не создаётся;
- расход является главным финансовым документом;
- связанный ремонт является технической записью и не удваивает сумму;
- аналитика считает оплаченные расходы один раз;
- старые ремонты без расхода учитываются только как резервная совместимость;
- повторное сохранение обновляет существующую связь;
- очевидные дубли связанных расходов автоматически нормализуются;
- в ремонте показывается связанный расход;
- при удалении ремонта можно оставить расход или удалить обе записи.
