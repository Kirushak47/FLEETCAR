# FleetPilot V6.1.3 Compact Mobile Service

На телефоне карточки Масло, Страховка и Техосмотр:
- находятся в одной горизонтальной ленте;
- листаются пальцем;
- занимают значительно меньше высоты;
- используют компактные иконки, текст, прогресс и кнопки;
- показывают часть следующей карточки, чтобы было понятно, что ленту можно листать.

На планшете три карточки остаются в одной строке.
На компьютере сохраняется крупный премиальный дизайн.
