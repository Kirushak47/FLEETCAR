# FleetPilot V4.1

Текущая V4.0 сохранена без удаления функций.

Добавлено:
- KPI автопарка только в аналитике;
- лента событий автомобиля;
- стоимость покупки и окупаемость;
- прогноз срока следующего ТО по истории пробега;
- рейтинг арендаторов;
- фотографии повреждений;
- автоматические рекомендации владельцу.

Не добавлено:
- расход топлива;
- доходность за километр.

Постоянная база fleetpilot.data.v1 и резервные копии сохранены.
