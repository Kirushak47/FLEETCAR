Изменено:
- приглашения отправляются через защищённую Edge Function;
- service_role не попадает в браузер или GitHub;
- функция проверяет JWT и роль владельца автопарка;
- нельзя приглашать пользователя в чужой Workspace;
- повторное приглашение обновляет срок и роль;
- существующему пользователю сохраняется приглашение для принятия после входа;
- новому пользователю отправляется настоящее Auth-письмо.
