# FleetPilot V10.5.3 — Data Recovery & Protection

1. Supabase → SQL Editor → New query.
2. Выполни `supabase_v10_5_3_data_recovery.sql`.
3. Загрузи файлы на GitHub.
4. Открой https://kirushak47.github.io/FLEETCAR/?v=105300
5. Нажми Ctrl+F5.

Восстановление:
1. Левое меню → Данные.
2. «Выбрать файл».
3. Выбери `RESTORE_THIS_BACKUP_FleetPilot_2026-08-04.json`.
4. Подтверди восстановление 4 автомобилей.
5. FleetPilot автоматически сохранит копию локально и отправит её в Supabase.

Сохранены все предыдущие функции: Workspace, роли, приглашения, Driver Portal, заявки на ремонт, Realtime Sync и корректное восстановление пароля.

Защита:
- пустая база не перезапишет облачную базу с автомобилями;
- перед сохранением создаётся облачная версия;
- хранится до 50 версий;
- восстановление версий доступно в разделе «Данные».
