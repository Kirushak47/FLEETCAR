# FleetPilot V14.0 — Vehicle Core

Главное обновление автопарка и профиля автомобиля.

- Новый Vehicle Core в профиле: состояние, Health Score, пробег, масло, активный сервис и последнее обслуживание.
- Сервисная задача получила тип обслуживания.
- Завершение задачи «Замена масла» автоматически обновляет пробег последней замены и следующий интервал масла.
- Завершение задачи по шинам автоматически обновляет дату установки и пробег комплекта.
- Если завершённую задачу снова открыть или удалить, технические показатели пересчитываются по последнему реально завершённому обслуживанию.
- Заявка водителя при передаче в сервис получает тип обслуживания по категории и остаётся связанной с ремонтом.
- Расходы, история и статус автомобиля синхронизируются через существующие связи сервиса.
- Статус «В ремонте» определяется активными сервисными задачами.
- Добавлен Health Score автомобиля (масло, страховка, техосмотр, активные/срочные ремонты).
- Desktop UI автопарка и профиля получил более спокойную типографику и компактные KPI.
