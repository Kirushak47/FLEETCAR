# FleetPilot V11.2 — Vehicle Alerts & Driver Service

1. Выполни `supabase_v11_2_vehicle_alerts_driver_service.sql`.
2. Загрузи все файлы на GitHub.
3. Открой https://kirushak47.github.io/FLEETCAR/?v=112000
4. Нажми Ctrl+F5.

Добавлено:
- иконка заявки гарантированно рисуется прямо в карточке автомобиля по `car_id`;
- иконка не зависит от текущей привязки водителя;
- карточка «Сегодня» открывает конкретный ремонт, документ или расход;
- водитель видит запланированный сервис в своём профиле;
- при создании/изменении сервиса водитель получает уведомление;
- сервисный план показывает дату, пробег, статус и комментарий;
- завершённые работы остаются в сервисной истории водителя.
