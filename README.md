# FleetPilot V5.3

Добавлено:
- город эксплуатации для каждого автомобиля;
- автодополнение городов из уже существующего автопарка;
- фильтр «Все города» на главной;
- после выбора города показываются только автомобили этого города;
- план недели, плановый доход, расходы и предупреждения пересчитываются по выбранному городу;
- город отображается на карточке и в профиле автомобиля;
- старые автомобили остаются совместимыми и получают пустое поле города.
