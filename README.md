# FleetPilot V3.6 — Custom Car Photo

Добавлено:
- загрузка собственной фотографии при добавлении или редактировании автомобиля;
- предпросмотр фотографии;
- удаление фотографии;
- автоматическое уменьшение до 1280×800;
- сжатие JPEG для экономии места;
- фото отображается на главной карточке;
- фото отображается внутри карточки автомобиля;
- без фото используется дизайн FleetPilot V3.5.

Данные и фотографии сохраняются в localStorage текущего браузера.
