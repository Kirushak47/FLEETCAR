# FleetPilot V3.7

Исправлено и добавлено:

## Налоги
- новый режим «Не плачу налоги»;
- в этом режиме VAT, PIT и взносы равны 0;
- ставка ryczałtu доступна только для Ryczałt;
- при Liniowy, Zasady ogólne и без налогов поле блокируется;
- Zasady ogólne имеет отдельный расчёт;
- VAT-поля блокируются в режиме без налогов.

## Главная по месяцам
- выбор конкретного месяца;
- общая аренда за месяц;
- ремонты и оплаченные расходы за месяц;
- налоги и взносы за месяц;
- чистая прибыль за месяц;
- по каждой машине отображаются доход, расходы и чистая прибыль за выбранный месяц.
