# FleetPilot V10.5 — Driver Portal Stage 1

1. Supabase → SQL Editor → New query.
2. Выполни `supabase_v10_5_driver_portal.sql`.
3. Загрузи файлы на GitHub.
4. Открой:
   https://kirushak47.github.io/FLEETCAR/?v=105000
5. Нажми Ctrl+F5 и войди повторно.

Добавлено:
- отдельный Driver Portal для роли Driver;
- назначение автомобиля водителю в Компания → Команда;
- автомобиль, пробег, город и дата назначения;
- документы водителя;
- заявки на ремонт;
- срочность и ошибки на панели;
- уведомления Owner / Coordinator / Mechanic;
- изменение статуса заявки в разделе Сервис;
- уведомление водителю при смене статуса.

Следующий этап:
- задания водителю;
- фотоосмотр;
- выдача и возврат автомобиля;
- автоматические дата, водитель, пробег и история в карточке автомобиля.
