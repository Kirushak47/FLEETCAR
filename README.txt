FleetPilot V17.2 — Driver Assignment System

Основа: V17.0 + V17.1 Driver Handover Fix.

Заменить в корне GitHub все файлы из этого архива.

Что изменено:
- В добавлении/редактировании авто поле водителя поддерживает список пользователей роли Driver.
- Можно выбрать существующего водителя по e-mail или ввести водителя вручную.
- При выборе аккаунта создаётся реальная привязка driver_user_id ↔ car_id.
- При смене водителя старое назначение снимается, новое создаётся.
- Если водитель уже назначен на другую машину, CRM предупреждает перед переназначением.
- В Автопарке видно назначенного водителя и состояние назначения.
- Для ручного водителя отображается «Введён вручную».
- Для аккаунта отображается «Ожидает подтверждения» или «Автомобиль принят».
- Кнопка «Принять автомобиль» скрывается, если активная выдача уже существует у этого водителя.
- Защита V17.1 от повторного submit / vehicle is already issued сохранена.
- Версия: V17.2 / build 172000.
