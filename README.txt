FleetPilot V18.6 — Driver Assignment & Fleet Status Fix

Что исправлено

1. СЕРВИСНЫЕ ИКОНКИ
- Полностью убран бейдж «Сервис OK» из рендера карточек.
- Дополнительно старый vehicle-service-indicator скрыт CSS, чтобы кешированная разметка не могла его вернуть.
- Старая иконка ключа/сервиса со счётчиком активных задач остаётся как раньше.

2. DRIVER PICKER В ПРОФИЛЕ АВТО
- Красивый поисковый выпадающий список.
- Поиск по имени, фамилии, e-mail и телефону.
- В строке водителя видно имя, e-mail, текущий автомобиль и статус.
- Результаты открываются по фокусу/вводу и закрываются после выбора.
- Ручной ввод остаётся отдельной опцией.

3. НОВАЯ ПРИЁМКА ПРИ КАЖДОМ НАЗНАЧЕНИИ
- Даже если тот же водитель снова получает тот же автомобиль, это новый цикл назначения.
- Перед новым назначением облачная связь сначала снимается и создаётся заново.
- Старый accepted/issued handover больше не должен считаться подтверждением новой выдачи.
- После назначения: Ожидает подтверждения -> водитель вводит пробег + фото -> подтверждает -> Автомобиль принят.

4. СТАТУС АВТОПАРКА НЕ ЗАВИСИТ ОТ ВОДИТЕЛЯ
- На линии / В ремонте / Свободен берётся только из выбранного статуса автомобиля.
- Назначение/отвязка водителя больше не меняет статус автомобиля автоматически.
- Сервисные задачи также не переносят карточку между колонками сами по себе.
- Если вручную выбрать «На линии», карточка сразу будет в «На линии» даже без водителя. То же для «В ремонте» и «Свободен».

5. АВТОПАРК
- «Ожидает приёмки» больше не используется как основной статус Fleet Board.
- Старые legacy-статусы pending/assigned/issued отображаются как «Свободен», пока пользователь сам не выберет нормальный статус.

6. КОМПАНИЯ -> ВОДИТЕЛИ
- Назначение через список водителей снова использует ту же unified-функцию, что и профиль автомобиля.
- Повторное назначение также создаёт новую приёмку.
- История handover учитывается только если она относится к текущему циклу назначения.
