FleetPilot V17.3 — Drivers Registry + Acceptance Fix

ЗАМЕНИТЬ ФАЙЛЫ ИЗ ЭТОГО АРХИВА В КОРНЕ GITHUB.

Что изменено:
- Компания → Команда больше не показывает пользователей с ролью «Водитель».
- В Компания добавлена отдельная вкладка «Водители».
- В реестре видны имя/e-mail, назначенный автомобиль и статус приёмки.
- Фильтры: с автомобилем, без автомобиля, ожидают приёмки, приняли, ручные записи.
- Из карточки водителя можно назначить/сменить автомобиль.
- Ручные водители, вписанные в автомобиль, также отображаются в реестре.
- Выбор водителя из списка + ручной ввод в автомобиле сохранены из V17.2.
- В Автопарке имя водителя и статус назначения сохранены.
- Кнопка «Принять автомобиль» жёстко скрывается после принятия машины этим водителем.
- После принятия остаётся только возврат автомобиля.

Версия: V17.3 / build 173000.
