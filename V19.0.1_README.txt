FleetPilot V19.0.1 — Driver Registry Read-Only Fix

Основа: чистый V19.0.

- Компания → Водители теперь только отображает текущий автомобиль.
- Назначать/снимать автомобиль из раздела Водители больше нельзя.
- Единственный источник текущей связи — профиль автомобиля.
- Если в профиле автомобиля водитель не указан, в Компании у водителя отображается «Без автомобиля».
- Старые cloud assignment записи не используются как fallback в реестре.
- При создании водителя убрана опция сразу назначать автомобиль.
